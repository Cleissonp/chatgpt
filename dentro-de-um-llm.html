O jogo da próxima palavra

Qual palavra pode vir depois?

Vamos usar uma frase simples e quatro possibilidades. A ideia é enxergar, antes do código, o que significa escolher a próxima palavra por probabilidade.

CONTEXTO

“O aprendizado de máquina é...”

A frase termina antes da próxima palavra. Agora precisamos representar as possibilidades.

SIMULAÇÃO EM PYTHON

Agora vamos transformar o slide anterior em código

O exemplo abaixo é completo: importa a biblioteca, cria variáveis, monta o dicionário de probabilidades, faz a amostragem e imprime o resultado.

Python · simulação completa
# Conceito simplificado de amostragem de palavras
import random

contexto = "O aprendizado de máquina é"

proxima_palavra_probabilidades = {
    "fascinante": 0.45,
    "complexo": 0.35,
    "uma": 0.15,
    "banana": 0.05
}

palavras = list(proxima_palavra_probabilidades.keys())
pesos = list(proxima_palavra_probabilidades.values())

resultado = random.choices(palavras, weights=pesos, k=1)

print(f"Texto gerado: {contexto} {resultado[0]}")
ESTRUTURA

Dicionário + variáveis

contexto, palavras, pesos e resultado são variáveis. proxima_palavra_probabilidades é um dicionário: palavra = chave; probabilidade = valor.

AMOSTRAGEM

random.choices()

A função escolhe uma palavra usando os pesos. Assim, “fascinante” tem 45% e “banana” tem 5% nesta simulação.

Saída possível
Texto gerado: O aprendizado de máquina é fascinante
Importante: isso é uma simulação didática da ideia de escolha probabilística. Um LLM real usa uma arquitetura muito mais complexa para chegar às probabilidades dos próximos tokens.

Arquitetura

Por dentro do “T” — Transformer

A arquitetura Transformer usa mecanismos de atenção para relacionar diferentes partes da sequência e construir uma representação contextual.

1. Tokens

O texto é dividido em tokens, que são representados numericamente pelo modelo.

2. Atenção

O mecanismo de atenção ajuda o modelo a relacionar diferentes partes do contexto. “Banco”, por exemplo, pode ter sentidos diferentes conforme a frase.

3. Saída

O modelo produz o próximo token e o processo de geração continua até formar a resposta.

Conceito

O que é IA generativa?

Em vez de apenas classificar ou reconhecer algo, o sistema pode gerar uma nova saída.

Entrada

Um prompt, contexto, dados ou instruções fornecidos ao sistema.

Saída

Texto, código, imagem, áudio ou outra forma de conteúdo gerado.

Modelos

Modelos treinados aprendem padrões que permitem produzir novas sequências.

Programação

Podemos incorporar esses modelos em aplicações usando bibliotecas e APIs.

Large Language Model

O que é um LLM?

Um modelo de linguagem de grande escala trabalha com sequências de tokens e usa o contexto para estimar o que pode vir a seguir.

Large

Grande escala de parâmetros e dados de treinamento.

Language

Foi projetado para trabalhar com linguagem representada como tokens.

Model

Um sistema matemático treinado para aprender padrões e produzir previsões.

Importante: LLM é o modelo. Uma aplicação como o ChatGPT oferece uma interface e funcionalidades para interagir com modelos.
Separando os conceitos

Modelo não é a mesma coisa que aplicação

Modelo

  • Processa entradas e produz previsões.
  • Possui parâmetros aprendidos.
  • Pode ser executado por diferentes aplicações.

Aplicação

  • Oferece uma interface para o usuário.
  • Gerencia contexto, histórico e funcionalidades.
  • Pode chamar um modelo por uma API.

Application Programming Interface

API: uma interface para programas conversarem

Uma API define uma forma estruturada de fazer uma solicitação e receber uma resposta.

→
Meu programa

Faz uma solicitação.

→
API

Recebe e encaminha a operação.

→
Serviço / modelo

Processa a solicitação.

←
Resposta

Volta para o programa.

Ideia-chaveAPI não é o modelo. É a interface usada para acessar uma funcionalidade.
O ciclo da comunicação

Request → API → Response

Request — requisição

O programa envia dados, parâmetros e instruções para solicitar uma operação.

Response — resposta

O serviço devolve o resultado da operação, normalmente estruturado em dados.

programa → API → modelo
programa ← API ← resultado

API local

Quais modelos estão disponíveis?

Antes de fazer uma pergunta, nosso programa pode consultar o servidor e descobrir quais modelos ele oferece.

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:1234/v1",
    api_key="lm-studio"
)

modelos = client.models.list()

for modelo in modelos.data:
    print(modelo.id)
ObserveO modelo.id será usado depois em model=... na requisição.

Dados estruturados

Uma mensagem é mais do que uma string

role

Define o papel da mensagem na conversa.

content

Contém o texto que será enviado.

messages

É a lista de mensagens enviada ao modelo.

messages=[
    {"role": "user",
     "content": "Explique um for loop."}
]
Conversação estruturada

system · user · assistant

system

Orientação

Define instruções e comportamento esperado do modelo.

user

Solicitação

Representa a entrada ou pedido do usuário.

assistant

Resposta

Representa uma mensagem produzida pelo assistente.

Prompt estruturadoO prompt passa a ser um conjunto de dados que o programa pode montar, alterar e reutilizar.
Chat Completions

Do Python para o modelo

response = client.chat.completions.create(
    model="SEU_MODELO",
    messages=[
        {"role": "system",
         "content": "Você é um tutor de Python."},
        {"role": "user",
         "content": "Explique um for loop."}
    ]
)

Programação

O modelo não devolve apenas texto

A resposta é um objeto estruturado. Precisamos navegar por seus atributos para chegar ao conteúdo.

response→choices→[0]→message→content

Estrutura

O objeto pode carregar informações como modelo, escolhas e metadados da execução.

Resultado

O texto gerado está dentro de message.content.

Resultado final

Como pegar a resposta?

print(
    response.choices[0].message.content
)
Do objeto à stringEsse caminho chega ao texto que queremos mostrar ao usuário.
